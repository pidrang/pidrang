# Contributing to Pidrang

First off, thank you for considering contributing to Pidrang!

## Local Setup

1. Clone the repository.
2. Install dependencies: `pnpm install`
3. Start the demo workspace: `pnpm nx serve demo-material`

## Branching Strategy

- `main`: Production-ready code.
- `feat/*`: New features or packages.
- `fix/*`: Bug fixes.

## Commit Guidelines

We follow Conventional Commits:

- `feat(core): add getList provider contract`
- `fix(supabase): handle null response in update`
- `docs: update README roadmap`
