# Security Policy

## Supported Versions

Pidrang is pre-1.0. Only the latest published minor version of each package is supported, and fixes are released as a new patch or minor version. Until the first release is published, only the latest commit on `main` is supported; please report against that.

## Reporting a Vulnerability

Please do not open a public GitHub issue for a security vulnerability.

Instead, report it privately by emailing the maintainers:

- rakoto.tsira@gmail.com
- fetrarij@gmail.com

Include a description of the vulnerability, steps to reproduce it, and its potential impact if known. We'll acknowledge your report and work with you on a fix and disclosure timeline.
